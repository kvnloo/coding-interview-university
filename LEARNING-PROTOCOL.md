# Optimized Learning Protocol for Coding Interview University

## Synthesized from 9 Learning Frameworks

This protocol integrates evidence-based strategies from:
1. **Ultralearning** (Scott Young) - 9 principles for accelerated learning
2. **Justin Sung** - Higher-order encoding and GRINDE mapping
3. **Flow Theory** (Csikszentmihalyi) - Challenge-skill balance
4. **Huberman Lab** - Neuroscience-backed protocols
5. **Bryan Johnson Blueprint** - Sleep and biological optimization
6. **Flow Research Collective** - 22 flow triggers
7. **Cutting-edge Learning Science** - Spaced repetition, interleaving
8. **Deep Work** (Cal Newport) - Focus and time blocking
9. **Colin Galen** - Competitive programming methodology

---

## Core Principles

### 1. The 4% Challenge Rule
Select problems approximately 4% harder than your current ability. This is the optimal stretch for flow state and learning.

### 2. 90-Minute Ultradian Blocks
Structure learning in 90-minute cycles aligned with natural brain rhythms:
- First 5-10 min: Warm-up (expect fluctuating focus)
- Middle 60-70 min: Peak focus zone
- Final 10-15 min: Natural decline, wrap up

### 3. Encoding Quality > Retrieval Quantity
Focus on understanding connections between concepts rather than rote memorization. Use GRINDE mind mapping for deep encoding.

### 4. Sleep-First Memory Consolidation
Neural rewiring happens during sleep, not during active study. Prioritize 7-9 hours of quality sleep.

### 5. Spaced Repetition (d = 0.54 effect size)
Review at expanding intervals: Day 1 → Day 2 → Day 4 → Day 7 → Day 14 → Day 30

## Problem Selection Strategy (Colin Galen Method)

### The 30-40% Rule
Find a difficulty range where you can solve 30-40% of problems without hints. This is your optimal learning zone.

### Time Limits by Difficulty
| Difficulty | Time Limit | Then |
|------------|------------|------|
| Easy | 15 min | See solution |
| Medium | 30 min | See solution |
| Hard | 45-60 min | See solution |

### Upsolving Protocol
1. Attempt during "contest" conditions
2. If stuck, try 15-30 min fresh later
3. Read editorial for key insight
4. Implement WITHOUT looking at solution code
5. Reflect: "What did I miss?"

## Flow State Protocol

### 22 Flow Triggers (Top 5 for Coding)
1. **Clear Goals** - Define exactly what to implement
2. **Immediate Feedback** - Run tests frequently
3. **Challenge/Skill Balance** - 4% stretch
4. **Complete Concentration** - No distractions
5. **Deep Embodiment** - Physical awareness

### The Flow Cycle
```
STRUGGLE (20-45 min)
    ↓ Brain loading, cognitive discomfort
RELEASE (15-20 min)
    ↓ Walk away, let unconscious work
FLOW (45-90 min)
    ↓ Peak performance, effortless
RECOVERY (30+ min)
    ↓ Rest, consolidation
[REPEAT]
```

## Encoding Strategies (Justin Sung)

### GRINDE Mind Mapping
- **G**rouped: Cluster related concepts
- **R**eflective: Ask "Why does this matter?"
- **I**nterconnected: Draw cause-effect links
- **N**on-verbal: Use symbols and diagrams
- **D**irectional: Show flow and priority
- **E**mphasized: Highlight key points

### Layer Learning
1. Build logical framework first (big picture)
2. Add concepts to framework
3. Fill in implementation details
4. Connect to related topics

## Deep Work Protocols (Cal Newport)

### Scheduling Philosophy
Choose based on your life:
- **Rhythmic**: Same time daily (recommended for most)
- **Bimodal**: Alternate deep/shallow days
- **Journalistic**: Fit it in (advanced only)

### Time Blocking
- Plan every 30-min block evening before
- Deep work in morning (peak brain)
- Batch shallow work afternoon
- Shutdown ritual at fixed time

### Shutdown Ritual
1. Review all open loops
2. Capture everything to task list
3. Check tomorrow's schedule
4. Say "Shutdown complete"
5. No work thoughts after

## Huberman Lab Protocols

### Morning Routine
1. Wake naturally (7-9 hours sleep)
2. Sunlight exposure 10-30 min
3. Delay caffeine 90-120 min
4. Exercise before first study block

### Gap Effects (10-Second Pauses)
- Insert random 10-sec pauses during practice
- Brain replays content at 20x speed
- ~1 pause per 2 minutes of learning

### Post-Learning Enhancement
- Cold exposure spikes adrenaline (memory lock-in)
- NSDR within 1 hour accelerates consolidation
- Caffeine AFTER learning (not before)

### Stress Management
**Physiological Sigh**:
- Two inhales through nose (no exhale between)
- Long exhale through mouth
- Activates parasympathetic system
- Use when stressed during problems

|----------|---------------|

| Day 4 | Second review |
| Day 7 | Third review |
| Day 14 | Fourth review |
| Day 30 | Fifth review |
| Monthly | Maintenance |

**Effect size**: d = 0.54 (meta-analysis)

### Interleaving (g = 0.42 effect size)
Mix problem types rather than blocking:
- NOT: 10 array → 10 tree → 10 graph
- YES: Array → Tree → Graph → Array → Tree...
